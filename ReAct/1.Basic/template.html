VScode에서 자주 사용되는 단축키

!, +, >, ., #, *, $, ^, ^^, (), {}

  1. html문서 템플릿 작성법 => html 파일 작성후
    ! => 엔터
  2. 태그를 여러개 생성하는 방법 => 태그명*갯수
    ex> div*5
  3. 태그 중첩해서 생성하는 방법 => 태그명>태그명>태그명...
    ex> div>ul>ol>*3
  4. 인접한 태그 생성하는 방법 => 태그명+태그명+태그명...
    ex> div+h1+h2+h3+span
  5. 태그{내용} 입력 후 enter
    ex> p{내용} enter
  6. 아이디 선택자 => 태그명#아이디명
    ex> div#name
  7. 아이디 선택자 자동 넘버링=> 태그명#아이디명$갯수
    ex> div{내용}#name$*n
  8. 클래스 선택자 => 태그명.클래스명
    ex> div.test
  9. 클래스 선택자 자동 넘버링 => 태그명.클래스명
    ex> div{내용}#name.test$*2
    ex> div{내용}.test#name$*2
  10. ^ 입력시, 한 단계 상위계층으로 이동 => 자식 태그로 만듦
    ex> div>ul>li^p
  11. ^^P 한 단계 아래로 이동 형식
    ex> div>ul>li>^^p
  12. ex> div>ul>li+p
  13. (태그,,,) 그룹으로 묶어주는 경우
    ex> div>(ul>li)+ol>li
  14. 자동 완성 기능 div#myid.classA.classB
    ex>
  15. 자동 완성 기능 div#myid.classA.classB 입력후 enter div#myid.classA (id와 클래스선택자를 동시에 생성)
